# java-lotto-precourse
# 로또 발매기 기능 요구 사항

## 1) 사용자 입력 받기
- **구입 금액 입력**
    - 로또 1장의 가격은 **1,000원**입니다.
    - 입력 금액은 **양의 정수**이며 **1,000원 단위**여야 합니다.
- **당첨 번호 입력**
    - **서로 다른 6개**의 정수를 입력합니다.
    - 각 숫자는 **1~45** 범위여야 합니다.
- **보너스 번호 입력**
    - **정수 1개**를 입력합니다.
    - **1~45** 범위이며, 당첨 번호 **6개와 중복 금지**입니다.
- **예외 및 재입력 규칙**
    - 잘못된 값이 들어오면 **`IllegalArgumentException`** 등 **명확한 예외 유형**을 발생시킵니다.
    - 에러 메시지는 반드시 **`[ERROR]`** 로 시작하며, **해당 단계부터 다시 입력**을 받습니다.
        - 예: `[ERROR] 금액은 1,000원 단위여야 합니다: 1200`

---

## 2) 로또 생성하기
- **발행 장수 산정**
    - `구입 금액 / 1,000` 만큼의 로또를 발행합니다.
- **번호 생성 규칙**
    - 로또 1장당 **중복 없는 6개 번호**를 생성합니다.
    - 각 번호는 **1~45** 범위입니다.
- **출력**
    - 발행된 각 로또의 번호를 출력합니다.

---

## 3) 당첨 검증하기
- **비교 대상**
    - 사용자가 구매한 각 로또 vs. **당첨 번호 6개 + 보너스 번호 1개**
- **등수 판정 기준 및 상금**

| 순위 | 조건 | 상금 |
|---|---|---|
| 1등 | 6개 번호 일치 | 2,000,000,000원 |
| 2등 | 5개 번호 일치 + 보너스 번호 일치 | 30,000,000원 |
| 3등 | 5개 번호 일치 | 1,500,000원 |
| 4등 | 4개 번호 일치 | 50,000원 |
| 5등 | 3개 번호 일치 | 5,000원 |

- **집계 및 출력**
    - 각 등수별 당첨 개수를 집계하여 출력합니다.
    - **수익률**을 출력합니다:
        - `수익률(%) = (총 당첨금 / 구입 금액) × 100`
- **종료**
    - 당첨 내역 및 수익률 출력 후 프로그램을 종료합니다.
